Política de Privacidad

Traductor Pantalla — Última actualización: mayo 2026

1. Datos recopilados

Esta aplicación utiliza Google AdMob para mostrar anuncios. AdMob puede recopilar el Identificador de Publicidad (Advertising ID) de tu dispositivo con fines publicitarios. No recopilamos ningún otro dato personal como nombre, email, ubicación, contactos, fotos o archivos.

2. Captura de pantalla

La app solicita permiso de grabación de pantalla (MediaProjection) exclusivamente para capturar la región que el usuario selecciona manualmente con el fin de traducir el texto visible. La imagen capturada se procesa completamente en el dispositivo usando Google ML Kit (OCR + traducción). No se almacena, no se transmite ni se envía a ningún servidor.

3. Superposición flotante

La app utiliza el permiso SYSTEM_ALERT_WINDOW para mostrar una burbuja flotante que permite activar la traducción sobre cualquier aplicación. Esta burbuja solo interactúa cuando el usuario la toca voluntariamente.

4. Procesamiento local

Todo el reconocimiento de texto (OCR) y la traducción se realizan en el dispositivo mediante Google ML Kit. Los modelos de idioma se descargan una vez y se almacenan localmente. Ningún texto ni imagen sale del dispositivo.

5. Servicios de terceros

Esta app utiliza los siguientes servicios de Google:

  • Google AdMob — muestra anuncios. Política de privacidad: https://policies.google.com/privacy
  • Google ML Kit — OCR y traducción en el dispositivo. No envía datos a servidores.

6. Eliminación de datos

Puedes restablecer tu Identificador de Publicidad en cualquier momento desde: Ajustes de Android → Google → Anuncios → Restablecer ID de publicidad.
